# Настройки кампании

## Основные разделы

На странице настроек кампании есть следующие крупные блоки:

- Domains
- Safe Page
- Flows
- Conversions
- Events
- Misc
- Postbacks
- Integration
- Scripts

Название кампании отображается в верхней части бокового меню. Значок карандаша справа от него позволяет переименовать кампанию, не возвращаясь на dashboard. Компактные иконки возле основных пунктов повторяют иконки в заголовках разделов; вложенные flows и steps остаются текстовыми.

Каждый основной раздел начинается с одинаково оформленных иконки, заголовка и короткого описания назначения. Это навигационные подсказки — они не меняют сохранение настроек кампании.

Во всех разделах редактора обычные кнопки действий имеют единый полный размер, а кнопки только с иконкой — ту же высоту, что элементы управления степами. Это правило сохраняется и для строк, добавленных без перезагрузки страницы.

## Domains

Здесь задаются домены, по которым runtime будет находить кампанию.

Группа **Domains list** содержит все домены кампании. В каждой строке рядом с доменом показывается результат проверки, а кнопка удаления расположена на одном уровне с полем домена.

Домены сохраняются в нижнем регистре, без схемы и пути. Допустимы обычные hostname, IP/`localhost` и необязательный порт. Wildcard разрешён только в начале: `*.example.com` совпадает с `a.example.com` и `a.b.example.com`, но не с самим `example.com`. Пересекающиеся правила между кампаниями запрещены; редактор покажет оба конфликтующих имени кампании. У новой и дублированной кампании список доменов пуст.

После сохранения YellowTDS автоматически записывает индекс `caching/runtime/domains.php` и полные настройки в `caching/runtime/campaign-<id>.php`. Runtime подключает эти PHP-файлы напрямую; при отсутствии или повреждении нужного файла запрос выполняет обычный поиск в SQLite. Следующее сохранение кампании снова создаёт полный набор файлов.

## Safe Page

Этот блок определяет, что отдать нежелательному трафику:

- folder
- redirect
- curl
- error

Также здесь могут быть domain-specific настройки Safe Page. Кнопка `−/+` возле пункта **Safe Page** в боковом меню сворачивает или разворачивает список доменов. Она появляется сразу после переключения в режим Domain-Specific; переход к странице конкретного домена автоматически раскрывает ветку.

В списках Redirect, Curl и HTTP Code можно добавить до пяти значений; хотя бы одна строка остаётся всегда. Новая строка создаётся с пустым значением, а удаление строки сохраняет остальные значения. Для Backfix можно задать до десяти URL или оставить список пустым.

## Flows

Это основная часть black-логики. В flow задаются:

- имя flow
- filters
- steps
- distribution
- optimize_for
- optimize_mode

Параметры **Save user path (Sticky)** и **JS Bot Detection** управляются наглядными переключателями On/Off. Save user path повторно использует те же варианты шагов, когда посетитель возвращается в уже посещённый flow; при этом сам flow заново определяется по фильтрам при каждом визите. Дополнительные настройки JS Bot Detection показываются только во включённом состоянии; отдельная рамка вокруг этого блока больше не используется.

Flows и steps сортируются перетаскиванием за одинаковую ручку слева от названия. Стрелки вверх/вниз для этого больше не используются.

Кнопка `−/+` возле пункта **Flows** сворачивает или разворачивает всё дерево, а такая же кнопка возле отдельного flow управляет только его steps. Состояние дерева сохраняется для каждой кампании; переход к скрытому step автоматически раскрывает нужную ветку.

## Integration

Способы подключения кампании собраны на одном экране:

- **PHP Connect** показывает адрес `api/phpconnect.php` и API-ключ кампании для комплектного `phpclient.php`.
- **JavaScript Connect** показывает готовый тег `<script>` и позволяет выбрать действие: заменить содержимое страницы, открыть результат в iframe или перенаправить браузер.

JavaScript Connect Action относится ко всей кампании, поэтому больше не отображается в разделе Flows.

## Scripts

Дополнительные механики:

- backfix
- replace transit or landing
- images lazy load
- redirect rules

Backfix, redirect-правила и ленивая загрузка изображений используют такие же явные переключатели **Off/On**, как общие параметры flow. Зависимые поля показываются только во включённом состоянии.

## Events

Здесь настраиваются включаемые пороги глубины прокрутки и видимого времени, а также список разрешённых пользовательских событий. Только эти включённые `scroll_*`, `stay_*` и custom events доступны для выбора во втором searchable chip-поле **Events** каждого S2S-правила. Performance/RUM-метрики не считаются S2S events. Семантика сбора описана в разделе [Events](events.md).

## Conversions

Здесь находятся каталог статусов кампании, дедупликация по Transaction ID, список принимаемых от разных партнёрских программ имён Transaction ID parameters, создание конверсии после успешной проксированной формы и опциональный website helper. Подробнее: [Конверсии и Postbacks](postbacks.md).

## Postbacks

Здесь находятся Key protection и исходящие S2S postbacks. Переключатель **Key protection** требует параметр `pbkey` во входящем postback; в поле **Allowed key values** перечисляются допустимые значения через запятую. При включённой защите отклонённые postbacks скрываются за `404 Not Found` вне Debug Mode.

Каждое S2S-правило имеет два searchable chip-поля: **Conversion statuses** из каталога Conversions и **Events** из включённых scroll/time/custom browser events. Выборы работают по OR: достаточно любого выбранного статуса или события. Подробнее о макросах, однократной отправке browser event и fire-and-forget доставке только для event-triggered S2S: [Конверсии и Postbacks](postbacks.md).

## Misc

В разделе **Misc** находятся переключатель **Uniqueness counting**, выбор метода и TTL, а также campaign timezone для отчётов и суточных conversion caps. Варианты сохраняют IANA-идентификатор и показывают текущее смещение UTC, например `Europe/Samara (UTC+04:00)`; оно может меняться по правилам летнего времени. Верхний selector timezone в статистике редактирует то же значение. Подробное описание идентификаторов, скользящего окна, flow-фильтра и статистики: [Подсчёт уникальности](uniqueness.md).
